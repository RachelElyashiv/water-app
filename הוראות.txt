איך מריצים את האפליקציה (גרסת שרת + מסד נתונים)
================================================

דרישה מוקדמת: מותקן Node.js (כבר קיים אצלך).

הפעלה ראשונה בלבד — התקנת רכיבים:
1. פותחים חלון פקודה (PowerShell / Terminal) בתיקייה הזו.
2. מריצים:  npm install
   (מוריד את הרכיבים הדרושים, פעם אחת).

הרצה רגילה — בכל פעם שרוצים להשתמש:
1. בתיקייה הזו מריצים:  npm start
2. פותחים דפדפן בכתובת:  http://localhost:3000
3. בסיום העבודה — סוגרים את חלון הפקודה (Ctrl+C) כדי לעצור את השרת.

מה חדש בגרסה הזו:
- חשבון משתמש אמיתי: הרשמה עם שם, אימייל וסיסמה, והתחברות.
- הנתונים נשמרים במסד נתונים (SQLite) בקובץ  data/water.db  שעל המחשב,
  ולא רק בדפדפן — כך אפשר להיכנס מכל דפדפן באותו מחשב ולראות את ההיסטוריה.
- כניסה מהטלפון: כשמריצים  npm start  מוצגת גם כתובת "מהטלפון"
  (למשל http://10.0.0.5:3000). אם הטלפון מחובר לאותה רשת Wi-Fi —
  אפשר לפתוח את הכתובת בטלפון ולהשתמש באפליקציה משם.
- התקנה כאפליקציה (PWA): בדפדפן בטלפון/מחשב אפשר "הוסף למסך הבית" /
  "התקן אפליקציה" — ואז היא נפתחת כמו אפליקציה רגילה ועובדת גם ללא רשת.
- תזכורות שתייה: בלשונית "הגדרות" אפשר להפעיל התראות "זמן לשתות"
  (כל כמה דקות, בין שעות שנבחרות) — גם כשהאפליקציה סגורה.
- גדלי כוסות מותאמים אישית ויעד יומי — בלשונית "הגדרות".

מה יש בפנים:
- לשונית "היום": רישום שתייה, יומן היום עם מחיקת רישומים,
  סימון צבע שתן, תיעוד אירועי כאב
- לשונית "מגמות": גרף שבועי וסיכום 30 יום
- לשונית "דוח": סיכום לרופא — העתקה או שמירה כ־PDF/הדפסה
- לשונית "הגדרות": יעד יומי, גדלי כוסות ותזכורות שתייה

הערה על תזכורות: כדי שיגיעו התראות גם כשהדפדפן סגור, צריך שהשרת
(npm start) ימשיך לרוץ ברקע, ושהאישור להתראות יינתן בדפדפן.

מבנה הקבצים:
- server.js        — שרת ה-Node/Express וה-API
- db.js            — הגדרת מסד הנתונים
- public/          — הממשק (HTML, CSS, JavaScript)
- data/water.db    — מסד הנתונים (נוצר אוטומטית בהרצה הראשונה)
- index.html       — הפרוטוטייפ המקורי (גרסה ישנה, ללא שרת)

הערה: זהו אב-טיפוס להדגמה ותיקוף הרעיון — לא מוצר רפואי.
